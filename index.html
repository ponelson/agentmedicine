Field note / July 2026

The field is building agent psychiatry. Agent internal medicine is instrumentation without a loop.

Agents can remember, reflect, delegate, and grade their own work. They still cannot reliably sense their own operating condition, regulate effort before failure, or govern the accumulated memory and external systems that shape what they do.

The narrower claim, stated up front because the broader one does not survive contact with the field: the signals exist. Observability platforms already track cost, latency, tool trajectories and quality; runtimes already implement retries, circuit breakers, rate limits, model routing and policy gates. What does not exist is a closed loop in which those signals are legible to the agent and shape its next action. This brief is about the loop, not about the absence of measurement.

Computing borrowed biological vocabulary broadly and biological mechanism selectively.

Before arguing that the field has missed something biological, it is worth auditing what it already took. The honest census is more interesting than the enthusiastic one, because the pattern of what transferred and what did not tells you where the next real borrowing is likely to be found.

Three verdicts run through every row below. Load-bearing means the biology actually drove the design and the mechanism transferred; remove the biology from the history and the invention does not happen. Loose means the inspiration was real but the mechanism diverged, so the analogy explains the motivation and not the math. Naming only means the vocabulary came from biology and nothing else did, which matters because borrowed names quietly import assumptions. Two-way marks the rarest and most valuable case: computing gave something back, and biologists found it in the tissue.

#What the pattern says

Borrowings hold when the constraint is shared

Every load-bearing row solves a problem physics imposes on both systems: energy per operation, distance between memory and compute, learning from correlated experience, spreading information through an unreliable network. Where the constraint is genuinely shared, the biology is a shortcut to a good answer.

Borrowings fail when only the word travels

Attention, guardrails, antivirus, forgetting. In each case the biological word smuggled in an assumption that the implementation does not honor, and the assumption then shaped a decade of intuition. Calling compaction "forgetting" is the live example: it makes deletion sound like damage when in biology it is the work.

And the largest gains came from abandoning fidelity

This is the part biomimicry enthusiasts skip. Backpropagation is biologically impossible. The transformer has no cortical analog. General-purpose GPUs beat purpose-built neuromorphic silicon by two decades and counting. The lesson is not that biology is a poor guide. It is that biology is a good source of problem statements and an unreliable source of solutions, because evolution optimized under constraints that a data center does not face. Use it to find what is missing, not to decide how to build it.

#Four kinds of non-correspondence, which the word “gap” hides

Asking what biology has that agents lack is really four questions, and collapsing them into one register is how a brief like this starts generating organ analogies indefinitely. Two of the four are about biology. One is about the limits of the exercise. The fourth runs in the opposite direction and is the one almost nobody writes down.

#Register two: name the precondition, not the organ

For anything that cannot transfer, the precondition is the useful output, because it tells you whether a workaround exists at all.

  • Apoptosis needs death to cost something. A cell that self-terminates sacrifices itself for the organism. A process that exits frees a container. Nothing is given up, so there is no altruism to model and no reason the mechanism would carry the meaning it carries in tissue.
  • Senescence and selection need mortality and turnover. Without a generation boundary there is no inheritance and no differential survival, so evolutionary framings apply only where someone deliberately engineers the culling.
  • Circadian rhythm needs unbroken time. An endogenous oscillator is a process that keeps running in the dark. An agent invoked in bursts has no continuous medium for one to run in, and a cron trigger is external scheduling wearing the word.
  • Critical periods need irreversibility. A window that closes only means something if you cannot go back. Snapshots make everything reversible, which is a capability, and it dissolves the concept rather than implementing it.
  • Territorial and kin behavior need scarcity of self. A microbiome cannot be forked. Most of population biology assumes copies are expensive.

The hard ceiling on the whole program

You cannot install a drive in a system that can edit its own drives. Hunger, pain and fatigue work because the bearer has no write access to them. They are wired below cognition, and the organism cannot decide to stop feeling them. Any interoceptive signal an agent can see, an optimizer can learn to route around, and any signal it can write, it can suppress.

This is a real limit on the strongest argument in this brief. The only workaround is enforcement in the runtime, outside the model, with the signal readable and not writable. That is worth building, and it is worth being clear that it is not the same thing as a drive. It is a governor. The distinction matters because a governor constrains behavior from outside while a drive shapes preference from within, and only the second produces an agent that stops because it wants to.

#Register three: what agents have that nothing alive has

This register is empty in most biomimicry writing, and it is the one that pays. Its function is diagnostic: it separates biological machinery that is missing from biological machinery that is unnecessary.

Exact rollback

Snapshot and restore. Biology is strictly one-directional: development, learning, injury, aging and scarring all run one way, and a great deal of physiological machinery exists to manage that fact. An agent can be returned to a prior state precisely. This is the deepest asymmetry in the document, and its consequence is that entire categories of biological apparatus may be unnecessary here rather than absent.

Forking

No organism duplicates itself instantly, at negligible cost, with identical internal state. This breaks individuality, scarcity, competition and mortality at once, and it grants something no living thing has had: counterfactual self-experimentation. Run one copy per hypothesis and keep the winner. No organism can A/B test its own life.

Readable internals

Weights, activations and the full trace are inspectable. Medicine has never had this, and imaging is a blurry proxy for it. This cuts against the bedside-examination argument in tab three: clinical method evolved to infer hidden state from surface signs, and an agent's state is not hidden. Exploit an observability medicine never had rather than imitating inference under uncertainty medicine could not avoid.

Direct instruction

You can tell an agent what to do in language and it complies. No biological channel resembles this. Animal training is slow, indirect and reward-mediated, and no organism accepts a behavioral specification in a sentence. This is the largest single asymmetry between the two systems, and it means every biological mechanism for slow behavioral shaping has a fast substitute here.

Wholesale state transfer

Complete memory moved between individuals in seconds. Horizontal gene transfer in bacteria is the nearest relative and it is slow, partial and stochastic. Nothing in biology transfers a full learned state intact, which is why the transplant idea in tab four is a better business than the biology that suggested it.

Replaceable cognition

The model can be swapped while memory persists. No organism receives a new brain and keeps its memories. The foundation-model-as-endosymbiont analogy therefore holds for dependency and fails for identity, and it makes memory rather than cognition the durable asset.

#Register four: borrowings that answer a question we never ask

Evolution optimized under energy scarcity, one-way time, no copying, no inspection, mortality and continuous embodiment. Any biological solution whose purpose is coping with one of those is a candidate answer to a question an agent never asks. Three live examples, including one that qualifies this brief's own best section.

  • Sleep is partly a workaround for not being able to pause. An organism cannot suspend itself, inspect its own memory and rewrite it deliberately, so it evolved an offline mode that does this indirectly on a schedule it cannot skip. An agent can be suspended and inspected directly. Keep the function, which is consolidation and clearance, and stop assuming the mechanism has to be periodic, unconscious, or bundled together.
  • Dreaming as noise injection is an indirect route. If the purpose is preventing overfitting to a narrow recent distribution, an agent can regenerate and perturb its own training distribution directly rather than relying on a stochastic process it cannot steer. The overfitted-brain reading is a good argument for the objective and a weak argument for the implementation.
  • Fibrosis becomes a choice rather than a fate. Scar tissue is irreversible in tissue because biology cannot roll back. Given snapshots, defensive accretion is reversible in principle, which strengthens the argument rather than weakening it: what is a tragedy in medicine is negligence here.

The qualification this brief owes its own thesis

The interoception argument is strongest for a singleton agent taking irreversible actions with consequences in the world, and weakest for a forkable agent doing reversible work. A forkable agent does not need a felt sense of when to stop, because it can try eight approaches and discard seven. Knowing when you have thought enough is a virtue under scarcity, and scarcity is exactly what forking removes.

That is a scoping of the program rather than a retraction of it. Physiology matters most where actions cost something and cannot be undone: money moved, messages sent, records changed, code merged, customers contacted. That is also precisely where enterprise agents are heading, which is why the argument strengthens as deployments become more consequential.

The operating discipline. Before importing any biological mechanism, ask which of the four registers it belongs to. For anything in register one or four, then ask what constraint it evolved to handle and whether an agent faces that constraint. If it does not, take the function and throw away the mechanism. That test would have caught the oncology analogy in tab three before it was written, which is why this section closes the census rather than sitting in an appendix.

Which sets up the actual argument. The borrowings above cluster heavily in one region: perception, learning, memory, cognition. The nervous system has been mined thoroughly. The rest of the body has barely been touched.

Agent psychiatry: what has been solved, what is being solved, and what the frame cannot reach

Almost every serious agent capability shipped since 2023 is a treatment for a mental complaint. The agent forgets. The agent does not learn from mistakes. The agent cannot judge its own work. The agent repeats itself. These are complaints about a mind, and the industry has answered them with a recognizable set of therapies.

#The four therapies, and their current state

Therapy one

The case file: persistent memory

Working, episodic, semantic, and procedural stores, scoped per agent and per team, with read and write permissions. Anthropic exposes memory through a standalone API outside the agent system, so an operator can scan it for sensitive data, tidy it, or copy it elsewhere. Experimental

Therapy two

Insight: reflection and critique

Reflexion, self-critique, chain-of-verification. The agent narrates its own failure and revises. Real gains on multi-step tasks, and a persistent weakness: an agent that reflects fluently on a doomed plan usually produces a fluent reason to continue. Shipped

Therapy three

Conditioning: rubrics and outcomes

RLHF and RLAIF at training time; at run time, a separate evaluator scores output against a written rubric and tells the agent what to fix. Anthropic's Outcomes went to public beta in May 2026. Spiral scores drafts against editorial principles and a user's voice, returning only what clears the bar. Wisedocs reports document reviews running fifty percent faster. Shipped

Therapy four

Sleep: offline consolidation

Letta's sleep-time compute, April 2025, established the frame: shift work off the response path into idle periods. Anthropic's Dreaming, research preview May 2026, applies it to memory curation across sessions and across a team of agents. Shipped, research preview

The caveat that governs all three numbers

Offline compute pays off when future queries are somewhat predictable from existing context, and the paper finds query predictability well correlated with how much sleep-time compute helps. When the next question is unrelated to what was consolidated, the dream produces output that is attractive and irrelevant. Two further qualifications belong on the same slide as the numbers. The headline figures come from benchmarks the authors constructed (Stateful GSM-Symbolic, Stateful AIME, Multi-Query GSM-Symbolic), with a single case study on a realistic agentic software task, so they are evidence of a mechanism rather than a forecast for your workload. And the accuracy gains are separable: up to thirteen percent on one benchmark and eighteen percent on the other, from scaling sleep-time compute rather than from merely enabling it. Every business case in tab four has to survive all three constraints.

#What Dreaming actually does to a memory store

Worth being precise, because the name invites overreading. It does not touch model weights. It is a scheduled asynchronous job that reads a batch of prior session transcripts plus the existing memory and emits a reorganized memory store, leaving the inputs intact so a team can approve, reject, or modify before deployment. Runs take minutes rather than hours, which is what makes an overnight or off-peak cadence practical. The four operations are merge duplicates, drop entries that have gone stale, promote a recurring pattern from many episodic events into one stable statement, and restructure for signal.

The third operation is the interesting one and the risky one. Promoting "asked about pivot tables six times" into "struggles with pivot tables" is exactly what schema formation looks like in biology, and exactly what a false generalization looks like in production. There is no scoring step that asks whether the promoted statement improved anything afterward.

#The risk the frame creates

Dreaming is a self-modifying write path into the artifact that governs future behavior. Memory poisoning has been a published attack class for over a year, and a scheduled process that rewrites its own operating instructions overnight is an unusually attractive target: the payload does not need to survive a session, only a consolidation run. The review-before-deploy option exists precisely because of this, and the moment it becomes tedious at scale, teams will turn it off. Set that aside as the security thesis in tab four.

#Where psychiatry runs out

Psychiatry's own historical limit is that it treats the mind as separable from the body. Every capability on the status board above treats the agent as disembodied cognition: better memory, better judgment, better rest for the mind. Not one of them concerns the agent's interior state, its metabolism, or the resident non-agent population it depends on to function. That is the next tab, and it is where I think the unclaimed ground is.

Internal medicine: the interior sense, the metabolism, and the population that is not the agent

Internal medicine asks a different question than psychiatry. Not what is the patient thinking, but what is the body doing, what is it signaling, what is it running on, and who else is living in it. Applied to agents, three findings fall out immediately, and the first one explains the failure mode everyone complains about.

#One. The interoception gap

Antonio Damasio's somatic marker hypothesis is the sharpest available statement of what Western medicine underweights. Patients with ventromedial prefrontal damage retain intact reasoning, intact language, intact memory, and lose the felt bodily signal that marks options as good or bad. They deliberate endlessly. They enumerate alternatives fluently. They choose terribly. Above all, they cannot tell when they have thought enough.

Read that description, then read an agent trace. Agents loop. They cannot tell when a plan has failed. They pursue a doomed approach with undiminished fluency for forty tool calls. The resemblance is worth taking seriously without being taken as a diagnosis. Missing interior signal is plausibly one important cause of agent perseveration, and it sits alongside poor termination criteria, reward misspecification, unreliable tools, and planners with no representation of their own failure. Damasio’s somatic marker hypothesis is also itself contested, with a substantial critical literature on its causal claims. What the frame buys is a candidate cause nobody is currently instrumenting, not a settled explanation.

The agentic equivalent of the mind-body connection is a channel carrying the state of the machinery underneath into the reasoning loop as a drive rather than a log line. Every signal it would need already exists. Every one of them is visible to human operators and invisible to the agent.

And the regulation target is wrong too

Peter Sterling's argument for allostasis over homeostasis: healthy bodies do not defend set points, they predict upcoming demand and adjust in advance, accepting temporary deviation to do it. Cortisol rises before you wake, not after you stand up. Agent operations is built almost entirely on homeostasis: thresholds, alerts, autoscaling in response to load already arrived. An allostatic agent would spend its interoceptive budget forecasting the shape of the next hour and pre-positioning for it. That is what sleep-time compute is, viewed correctly, and it is why it belongs in this tab rather than the last one.

#Two. Metabolism, and the missing forcing function

In biology, rest is not a preference. It is metabolically enforced. Glymphatic clearance flushes interstitial waste from the brain during sleep. The synaptic homeostasis hypothesis of Tononi and Cirelli proposes that sleep's core function is downscaling synaptic weights that grew all day, preventing saturation and restoring the capacity to learn tomorrow. That remains a hypothesis and a contested one, and the argument here does not depend on it being the whole story: what matters is that clearance and renormalization are real offline-only processes, and that the organism has no authority to skip them.

Nothing forces an agent to rest. Downtime is a budget line, which means it is the first item cut when load rises. This is precisely backwards from the biology, where the maintenance work becomes more necessary as the day gets harder. Any operator who runs consolidation only when there is spare capacity has built a system that stops learning exactly when it most needs to.

Forgetting is the work, not the loss

This is the single largest unclaimed position in the field. Synaptic downscaling and microglial pruning are expensive, active, targeted deletion, and they are what makes generalization possible: the details you drop are what would otherwise be overfitted. Every agent memory product on the market is additive. Compaction is framed as a cost saving and treated as regrettable. No vendor sells deletion as the product. The first one to ship principled forgetting, with an audit trail of what was dropped and the evidence for dropping it, will look obvious in retrospect and will own a category nobody is currently competing for.

#Three. The census of what is not the agent

The human body contains several distinct classes of not-you, and they are not interchangeable. Getting the taxonomy right matters, because each one fails differently.

Endosymbiont

The mitochondrion is the foundation model

Foreign in origin. Acquired rather than inherited through the organism's own line. Carries its own genome that you cannot read. Supplies the metabolism of everything else. You did not build it, you cannot inspect it, and nothing runs without it.

Endogenous retrovirus

Inherited foreign code that became structural

Roughly eight percent of the human genome is viral in origin, and some of it became essential: syncytin, which builds the placenta, is a repurposed viral envelope gene. The agent analog is the copied prompt patterns, scaffolds, and scraped conventions that entered as foreign material and are now load-bearing infrastructure nobody audits.

Microbiome

The context supply chain

Embedding models, vector indexes, rerankers, caches, MCP servers, tool endpoints, memory stores, guardrail models, and the outputs of other agents. Acquired from the environment, non-inherited, metabolically essential, wildly variable between installations, and a manageable health variable that nobody manages as an ecology.

The microbiome is the answer to the original question, and it earns the label on every criterion that matters in the biology: it is not you, each individual acquires it from the environment rather than inheriting it in the genome, you cannot function without it, its composition differs enormously between individuals, and its composition is a health variable that responds to management. Which means the failure modes translate exactly.

The immunology correction

Security borrowed the vocabulary of infection and inherited the wrong model with it. Barriers, quarantine, vaccination. But the hard problems in immunology are not exclusion, they are tolerance and autoimmunity: deciding which residents are self, staying calm about the ones that are, and attacking the ones that turn without attacking the host. An agent's context is full of tolerated foreign material by design. Retrieved documents, tool output, other agents' conclusions, its own consolidated memories. The interesting security question is not how to keep things out. It is how the agent distinguishes self from non-self among the material it has already swallowed, and what it does when a trusted resident starts issuing instructions.

#Three point five. Expression state, which the genome framing was missing

The census above has a hole. It names the genome (weights), the foreign sequence that became structural (inherited conventions and scaffolds), and the resident population that is not the organism (the context supply chain). It has no account of regulation: how a fixed genome produces radically different behavior without being edited. That is epigenetics, and its absence is why the endocrine section below has a signal with no delivery mechanism.

Two facts do the work. First, differentiation: a liver cell and a neuron carry identical DNA and are permanently, stably different, because expression state was set during development and is then maintained. The counterpart is a specialist agent derived from a general model whose specialization is held in loaded adapter weights rather than in restated instructions, and held stably, which is the part prompt-based specialization cannot do. Second, heritability of the marks: methylation and chromatin state pass to daughter cells, and in some cases across generations. That is the mechanism a swarm needs. A posture set at the top propagates to spawned children without being re-instructed, re-argued, or re-prompted into each one.

The engineering counterpart is adapter and soft-prompt activation switched at runtime in response to assessed conditions, with the active set inherited by child agents. Marking this honestly: the components exist and are well understood, hot-swapping them on live inference paths in response to runtime signals is buildable, and it is close to nonexistent in production. This is a proposal, not a description of something already happening.

#Four. The endocrine system, or global posture

Everything above regulates locally. The endocrine system does the opposite: a gland releases a chemical into general circulation, and every tissue carrying the matching receptor changes behavior at once, on a timescale of minutes to days rather than milliseconds. That is a distinct control regime, and it has no counterpart in agent design.

Agents are steered almost entirely by local, instantaneous instruction. A prompt adjusts this turn. A tool permission gates this call. There is no slow, diffuse signal that shifts an entire deployment into a different operating posture: raise precision and lower verbosity, narrow tool scope, escalate sooner, prefer the more expensive model, shorten the leash on autonomous write actions, and hold that state for six hours because the assessed risk level changed. What exists instead is a config deploy, which is a different thing: discrete, all-or-nothing, and requiring a human to decide and ship it.

#Five. Circulation, perfusion, and the shunt

Tab one lists circulatory cooling as convergent engineering rather than a borrowing. That was the wrong scope. The circulatory system's more interesting property is not heat transport, it is that it is a rate-limited distribution network whose regulated variable is pressure, whose failure mode is local starvation despite adequate total supply, and whose most striking behavior is triage.

Three transfers worth having. Perfusion rather than throughput: the number that matters is not total capacity but whether each component is receiving enough, which is exactly the distinction between a healthy fleet-level token budget and a starving critical subagent. Backpressure and autoregulation: tissues locally dilate and constrict to claim what they need, and the system holds pressure without central scheduling, which is a better model for queue management across parallel subagents than any central orchestrator. Shock: a distribution failure in which total volume is fine and perfusion fails anyway. Agent deployments produce this regularly and describe it as a rate limit problem.

The shunt is the part that connects back. Under acute stress the body constricts flow to the gut and the skin to preserve the brain and the heart. Digestion is not important right now. That is a defensible triage on a timescale of minutes and a serious pathology on a timescale of weeks, which is precisely the argument this brief already makes about consolidation being cut first under load. The biology says the reflex is correct and the chronic version is the disease.

#Six. The enteric nervous system, and the sensory boundary

Roughly five hundred million neurons sit in the gut wall, organized into their own plexuses, capable of running peristalsis and local reflexes with the vagus nerve cut. It is a genuinely semi-autonomous nervous system in the periphery, and it reports upward far more than it receives downward. The spinal reflex arc makes the same point more sharply: a hand leaves a hot surface before the brain is informed, because the decision was made two synapses away from the sensor.

The counterpart is the decision-making that already happens outside the reasoning loop and is not designed as such: retrieval filters, rerankers, guardrail classifiers, tool-side validation, edge gateways, retry logic. These make consequential choices about what the model ever sees, and they are treated as plumbing rather than as cognition. The design question the biology raises is the right one: how much local autonomy belongs in the periphery, what does it escalate, and in which direction does the traffic actually flow. Most agent architecture diagrams show the model at the center commanding outward. The gut suggests the opposite topology is at least as likely to be correct, and the security framing follows from it: a boundary is a sensing organ with local reflexes, not a wall.

#Seven. Continuous filtration, and a bias this brief had

Everything above treats cleanup as an offline batch process, and that is a bias rather than a finding. Sleep is periodic. The kidney is not. It filters continuously, at rest and under load, and an organism that could only clear waste while asleep would not survive the day.

The architectural contribution is not the continuity, though. It is the order of operations, and it inverts how context management currently works. The glomerulus does not decide what to remove. It filters on size and charge alone, passing water and small solutes into the filtrate while retaining cells and large proteins, and it makes no judgment whatever about value. The tubules then reabsorb, and above ninety-nine percent of filtered water is recovered. Selection for worth happens on the rescue, not on the discard.

Current compaction does the opposite: it decides what to keep and drops the remainder, which means every retention decision is made under the full pressure of a live task by the same process that is trying to complete it. The renal pattern says to invert that. Filter aggressively and by default, then reabsorb against explicit value criteria, and let the two stages be separately tunable and separately auditable. Osmoregulation is the second half: the regulated variable is context pressure and concentration, not merely the removal of waste, which is a different objective from token count.

Marked honestly: streaming compaction, sliding windows and mid-session pruning all exist. This is not an absent capability. It is an under-theorized one, running on heuristics that nobody has expressed as a two-stage filtration model with a defensible reabsorption policy.

#Eight. Fibrosis, which is the right name for something everyone has seen

Acute inflammation recruits immune cells, clears the damage, and resolves. Chronic inflammation does something else: fibroblasts activate, and functional tissue is progressively replaced by stiff, non-functional scar. The organ keeps its shape and loses its compliance, and the process is largely irreversible.

The counterpart is the defensive accretion around an agent's execution path. A tool drifts, so a wrapper goes in. An endpoint returns malformed output once, so a validation branch goes in. A model does something alarming, so three sentences of prohibition go into the system prompt. Every patch is locally correct and permanently retained, and the aggregate is an environment the agent navigates rather than uses. Cognitive mobility falls while every individual defense remains justified.

The existing vocabulary for this is technical debt, and fibrosis is the better term for a specific reason: debt implies a deliberate trade with a repayment schedule, whereas this is an immune response that overshot. Nobody chose it and nobody is servicing it. The clinical implication is the one worth carrying: fibrosis is prevented by resolving inflammation early, not by removing scar later.

#Nine. Bedside examination, which is the method the whole tab has been missing

Tab two catalogs the failure modes. The panel above catalogs the vitals. Neither of those is a procedure, and internal medicine's actual contribution is not its anatomy, it is its method: presenting complaint, history, physical examination, differential diagnosis, targeted investigation, therapeutic trial, response assessment. Current practice has none of this. An agent fails, the trace is reviewed afterward, and that is an autopsy. The discipline being described here is the one that works on a living patient.

What that implies operationally is specific. When the vitals go abnormal, before the failure, the response is neither termination nor restart. It is a protocol: isolate the agent from production traffic while keeping it alive, run targeted probes designed to discriminate between candidate causes (retrieval corruption presents differently from context saturation, which presents differently from a poisoned memory, and a probe can separate them), form a diagnosis, apply one intervention, and measure the response before applying a second. One variable at a time, which is the part engineering culture finds hardest.

Two honest problems with this. Observation changes the patient: an agent moved into a diagnostic environment is no longer in the conditions that produced the symptom, and the clinical literature has a name for that class of artifact. And a therapeutic trial requires the pharmacology this tab admits it lacks, because applying one intervention and measuring the response is meaningless without a dose and a half-life. Bedside examination is the right frame and it is downstream of the gap named below.

#What is still missing from this tab

Naming the gaps is cheaper than defending a claim of completeness. The largest remaining one is structural rather than anatomical: there is no pharmacology here. A document arguing for internal medicine and omitting the discipline of intervention is missing more than any single organ system. Dose and response curves. Half-life, which is the question of how long an intervention persists after you stop applying it. Therapeutic window, meaning the gap between the dose that works and the dose that harms. Interaction effects between simultaneous interventions. Contraindications. Every one of those has an obvious agentic reading, and the field currently ships interventions with none of that vocabulary: a system prompt change has a dose nobody measures, a half-life nobody characterizes, and interactions nobody tests.

Also absent, and worth listing rather than quietly skipping: lymphatic drainage and immune trafficking as distinct from circulation; glymphatic clearance, which is the specific mechanism that makes sleep non-negotiable in mammals and therefore the sharpest available argument against treating downtime as discretionary; senescence and aging, because nothing here describes what an old agent deployment looks like or why it degrades; and the microbiome's own development, which in humans is a years-long colonization sequence rather than an inoculation.

One candidate considered and mostly declined. Oncology, offered as a frame for runaway recursive subagent spawning, is the weakest transfer reviewed for this brief, because the phenomenon it describes already has better-specified engineering vocabulary: depth limits, propagated budget tokens, supervision trees, circuit breakers, cgroups. Relabeling a resource quota as a tumor suppressor loses precision rather than gaining it. One thing does survive, and it is worth stating because it is not about resources at all: a tumor is a cell that passes every self-check. It is genuinely you, which is why it is not rejected. The hard multi-agent failure is not the subagent that violates a rule, it is the population of subagents each behaving correctly under its own local instructions and collectively producing a pathology no quota detects. The related fact is that treatment applies selection pressure, so filtering a behavior selects for the variants that evade the filter. Those two observations belong in a guardrail design conversation. The rest of the oncology frame does not.

#What internal medicine would actually build

  1. An interoceptive channel. The nine vitals above, written into context as pressures that shape policy, not as numbers to be reported. The test of success is that the agent stops on its own.
  2. Two-stage continuous filtration. Aggressive default clearance of the live context, with a separately tunable and separately auditable reabsorption policy deciding what is rescued. Selection on the rescue, not on the discard.
  3. A REM job alongside the NREM one. Constraints relaxed, memory fragments recombined, counterfactual variants of past failures generated, and then everything filtered by a verifier. Generate-then-filter is what separates this from hallucination.
  4. Principled forgetting with an audit trail. Every memory carries a predictive-value score, decayed over time, and gets evicted on evidence. What was dropped and why is a queryable record.
  5. Supply chain health monitoring. Index freshness, embedding drift, per-tool signal-to-noise, self-generated content share of the corpus. The last of those is the model-collapse early warning and almost nobody tracks it.
  6. A diagnostic protocol and a place to run it. Probes that discriminate between candidate causes, one intervention at a time, response measured before the next. This is the item with the clearest product shape and the same buyer as the attribution harness in tab four.
  7. Inheritable expression state. Posture carried in loaded adapter weights rather than restated instructions, and passed to spawned children automatically. The delivery mechanism the global-posture argument requires.
  8. Tolerance policy. Provenance on every item in context, and a defined posture for what a resident is allowed to instruct.
  9. Controlled dirt exposure. A development regime that deliberately includes malformed data, degraded tools, and adversarial phrasing, on the hygiene-hypothesis rationale.

The business: sell amortization and governance, not agent wellness

Buyers do not purchase agent wellness. They purchase cost per resolved task. The CFO-legible claim is: precompute reusable state during non-interactive windows, then measure whether the amortized cost is lower than reconstructing that state repeatedly during live work. It is an infrastructure pitch, not a wellness pitch.

A word this brief used wrongly and has stopped using. Earlier drafts called this offline compute arbitrage. Arbitrage implies the compute itself is bought more cheaply, which is true only where the customer actually has a pricing differential to exploit: a batch tier, spot capacity, reserved capacity already paid for and idle, or off-peak commit pricing. Batch APIs commonly do discount around fifty percent, so the arbitrage framing is available, but it is a conditional claim that depends on where the consolidation job runs. Absent that differential the real mechanisms are narrower and still worth money: amortizing one computation across many later queries, displacing work out of the latency-critical path, smoothing capacity, and improving cost per resolved task. State the mechanism you actually have. A CFO who discovers the arbitrage was rhetorical will discount everything else on the page.

#Why the wellness framing fails, in three

The buyer has no line item for it

There is no budget called agent wellbeing and there will not be one. There is a budget for cost per resolved ticket, escalation rate, and time to first useful output. Every claim has to land in one of those three.

The engine is closing

Letta shipped sleep-time compute in April 2025. Anthropic shipped Dreaming in May 2026. Building a better consolidation engine means racing platform vendors who own the traces, the runtime, and the distribution. Do not take that fight.

A generic corpus has no value

This is the hard one, because the corpus is the instinct. The lift comes from the customer's own execution traces, not from anything pre-packaged. Curated stimulus material is a commodity from the day it ships.

#Four positions that survive the objections

Position one, and the strongest

The attribution harness

Everyone is about to run consolidation. Almost nobody will be able to prove which consolidated memory caused which change in outcome, or notice when the process starts degrading performance instead of improving it. Tie every memory entry to the tasks it entered, score it on whether it reduced error, decay the score, and produce a ledger. Sell it as the thing that makes dreaming auditable enough to leave on unattended.

This is no longer uncontested, and the brief was wrong to imply it was. MemTrace (Deng et al., Zhejiang University and Alibaba, arXiv 2605.28732, May 2026) turns memory pipelines into executable memory-evolution graphs, benchmarks failure modes across Long-Context, RAG, Mem0 and EverMemOS, attributes a wrong answer to the specific upstream operation that caused it, and closes the loop by feeding attribution signals into prompt optimization for up to a 7.62 percent end-task gain. Adjacent work has arrived alongside it: MemFail, A-TMA, DynamicMem. Research activity is now dense here. What no one obviously owns yet is the enterprise control plane that unifies causal attribution, deletion governance, and production remediation under one policy engine with approvals and rollback. That is a narrower and more investable claim than novelty, and measurement alone is not the moat, because measurement platforms commoditize. The defensible asset is longitudinal outcome-linked memory data, deep runtime integration, and approval workflows a regulated buyer will accept.

Position two

Memory hygiene and poisoning defense

Consolidation is a self-modifying write path into the artifact that governs future behavior, and a payload only has to survive one overnight run to become policy. Review-before-deploy exists in the platform and will be switched off the moment it becomes tedious at scale, which is roughly the second week. The product is automated review: provenance on every proposed memory change, anomaly detection on the diff, and a policy engine for what a consolidation run is allowed to promote. This is a security purchase, which is a better budget than an efficiency purchase.

Position three

Forgetting as a service

Correction to an earlier claim. This brief previously said nobody sells deletion. That is false. Mem0 ships LLM-driven ADD, UPDATE, DELETE and NOOP as production memory operations, and learned deletion is an active research line: Memory-R1 (Yan et al., arXiv 2508.19828, now ACL 2026) trains a memory manager on those four operations with outcome-driven reinforcement learning, with Mem-alpha and memory-as-action following. The accurate gap is not the delete operation. It is deletion governance: evidence for why a specific item went, a lineage record that survives audit, a retention policy expressed in predictive value rather than in days, and a rollback path. Deletion as a learned action optimizes task accuracy. Deletion as a governed process is what a compliance owner can sign. The second one is unbuilt. The incentive argument still holds, since storage and token volume are revenue for incumbents. Three separate buyers: the operations owner who wants lower cost, the quality owner who wants better generalization, and the compliance owner who wants defensible retention. The audit trail is what makes it sellable rather than frightening.

Position four

Cold-start seeding, or the strain bank

This is your corpus idea in the form that works. Not curated art or generic stimulus material, but validated consolidated memory and tool ecologies harvested from mature agents in a specific vertical, transplanted into a new deployment to skip the colonization period. The value is in curation and provenance, the moat is in accumulated donors, and the model is closer to a strain bank or a seed library than a content library. Note the obvious hazard: transplanting a donor's pathologies along with its competence. That hazard is also why the attribution harness in position one is the prerequisite rather than an add-on.

#The minimum viable product, stated concretely

“Agent internal medicine” is a thesis, not a product. The first product is narrower: a versioned memory control plane that links every memory change to its provenance, its downstream use, its measured outcome, and its deletion status. Everything else on this page is a later module.

What it has to capture to be worth buying, and each line is a build item rather than a slogan:

  1. Session and tool traces, retained and addressable.
  2. Memory diffs before and after every consolidation pass.
  3. Provenance for each promoted statement, marking observed against inferred against inferred-from-inferred.
  4. Retrieval linkage: which later tasks pulled each memory, and whether the generator actually used it.
  5. Outcome deltas per memory: task success, cost, latency, escalation rate.
  6. Replay or A/B with a given memory included and removed. This is the only way attribution becomes causal rather than correlational, and it is the hardest item on the list.
  7. Quarantine and rollback, at the level of a single memory rather than the whole store.
  8. Retention and deletion lineage that survives an audit.

The moat is not the measurement. Measurement platforms commoditize, and MemTrace shows the research is already here. The defensible assets are the longitudinal outcome-linked record, which compounds and cannot be bought; runtime integration deep enough to intervene rather than only observe; and an approval and policy engine a regulated buyer will actually sign off on. The first two are engineering. The third is why this is a company rather than a feature.

#The custody question

Consolidated memory is derived intellectual property, and it is worth more than the raw traces it came from, in the same way a schema is worth more than the episodes it generalized. If dreaming runs inside a vendor's platform and the resulting schemas live there in a proprietary shape, the operating knowledge of the company accumulates somewhere the company does not control.

Worth noting that this appears to have been anticipated. Anthropic put memory behind a standalone API outside the agent system specifically so a business can build its own pipelines around it, scan it for sensitive data, tidy it, or copy it into other systems. That is an explicit anti-lock-in signal, and an open memory format is the right thing for a buyer to demand and the right thing to watch. If open formats win quickly, the custody pitch weakens considerably, which would be a good outcome for buyers and a reason not to build a company whose only thesis is custody.

#The workload underneath

Unglamorous and worth stating plainly, because it determines who else has a stake. Consolidation requires retaining raw execution traces indefinitely: enormous, unstructured, low value per byte, occasionally decisive. Those traces are cold almost all the time, then read in bulk sequentially on a schedule when the consolidation job runs. The access pattern is write-once, sleep, full scan, repeat. That is a data lifecycle problem with a nightly scan profile, not a database problem, and the retention economics are what decide whether an organization can afford to keep enough history for consolidation to find anything.

#The pitch, by audience

To the CFO

You spend a known amount per resolved task. Consolidation run on off-peak compute cut peak-hour tokens and escalation rate by a measured margin. Here is the payback period, and here is the ledger that shows which memories earned it.

To the CTO

Your agents repeat the same mistakes across sessions, and your memory store only grows. We score every memory on whether it reduced error, delete the ones that did not, and tell you when a consolidation run made things worse before it reaches production.

To the board

Derived agent memory is becoming the operating knowledge of the company. Right now it accumulates inside a vendor's platform, in a shape we do not own, with no record of what was kept or discarded. That is a custody question, not an IT question.

#What would falsify all of this

  • The lift is really prompt quality. If consolidation gains turn out to be mostly better instructions discovered by accident, the product is a prompt optimizer and the biology was decoration.
  • The predictability constraint binds hard. Offline compute pays only when future queries are somewhat predictable from existing context. If real enterprise query distributions are less predictable than benchmark ones, the arbitrage never amortizes and every number in tab two is a benchmark artifact.
  • Platform vendors ship attribution natively. The measurement moat is the best position here and the most obviously absorbable. Assume eighteen to twenty-four months.
  • Weight-level learning arrives. Dreaming deliberately does not touch weights. If continual fine-tuning on execution traces becomes safe and cheap, memory curation becomes a transitional technology and the whole category compresses.
  • Forgetting turns out to be dangerous in practice. Deletion is irreversible and audit regimes hate it. If the compliance answer is always keep everything, principled forgetting becomes a shadow index rather than a product.

The through-line: the field spent three years building the mind and has not started on the body. The interoception gap explains the failure mode everyone already complains about, forgetting is the mechanism everyone has miscategorized as a cost, and the microbiome is a real ecology that no operator currently manages as one. None of the three requires new research to begin. All three require taking the biology seriously enough to notice that the nervous system is not the whole organism.
